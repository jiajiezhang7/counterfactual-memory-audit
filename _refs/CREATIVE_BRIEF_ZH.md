# CMA 真机视频制作说明

这是离线制作的素材包，主视频为三分钟整体结构中的真机和方法模块。完整仿真由另一台实验机器制作，本包不包含仿真运行画面。

## 阅读与拼接

先看包根目录的 `START_HERE.html`，再看 `03_annotated_clips/02_task1_main.mp4`。主模块：开场8秒、方法17秒、task1 48秒、task2 22秒、汇总17秒，合计112秒；仿真占另外68秒。`05_editing/master_timeline.csv` 标明在180秒整体视频中的位置。

核心问题：成功抓起并放置一个物体，是否意味着策略根据记忆选择了正确托盘？主配对两个视频都放到左托盘；左来源成功，右来源错误。该例用于解释总体5/9“完成但目标错误”，不代表每次试验都这样。

## 主镜头来源与阶段

- Task1：`core_left_02_M0_R1` / `core_left_02_M1_R1`，blind IDs `e13f9b45270fda68` / `209d0366367bb3fc`。历史分别为 `h_core_left_left_02` / `h_core_right_left_02`。
- Prefix 取两份完整历史导出各自第16–24秒，1×播放，包含来源托盘到中央的搬运。前后等待被剪去；完整历史保存在 native clips 内。显示的是两份记录中的片段，不是同一次连续录制。
- Decision 用两次 query 中实际相同的 canonical 图像；已直接比较图像、状态、全部模型 current arrays 和保存动作。图像对比发生在打码前，不能拿打码图证明数组一致性。
- Suffix 从各自首个实际 sent command 对齐，完整保留约8.4秒和8.8秒的后缀与终态。较短一侧在真正结束后静止并标 End。它们经过不同的物理复位，不能把画面称为物理 bit-exact reset。
- 历史 prefix 是记忆形成的过去；保存的五条首段命令则属于策略 suffix。`Saved action → closed-loop continuation` 专门区分这两个概念。

方向对照取 `core_left_03` 的R1两次执行。主片前10秒后显式切到各自终态，较长后缀的中间部分未收入48秒模块；完整正常速度对照另在 `08_direction_full.mp4`，不能将片段长度误认为控制器执行时长。

## Task2 的处理

主选是橙色 `20260911T204344_4094acc502a0`、绿色 `20260911T213327_25bac7661d40`；二者为训练集中的专家遥操作示教。原始 episode metadata 和阶段 events 保留在 provenance。

遵照用户指定，主画面不叠加训练来源或讲解用途说明，由用户在另外说明中披露；阶段条用 `SUFFIX — TARGET SELECTION`，不将遥操作标为 policy takeover，不伪造 formal rollout ID，不从训练片计算Table3统计。论文结果卡与动作展示分开。

22秒版：prefix为1.5×，decision停顿2秒，后缀从各自标记边界后3秒开始、正常速度播放。只省略边界之后的初始等待；画面明确显示 excerpt 及省略时间。`09_task2_extended.mp4`保留正常速度完整事件和完整后缀，供不受22秒限制的替换剪辑。

备用素材为两类下一条训练episode。没有把橙色的history和绿色的suffix拼成一条伪造失败，也没有生成或改变物体动作。

## 图表口径

Task1 的32次核心标签从现存记录重新核算；56次总记录中的same-origin、AA、ordinary对照保留独立身份。八个pair是独立单位，memory和seed不是额外独立样本。分类矩阵包含6正确、6错误、19未表达和1混合/其他；点标表示完成操作。

Task2 的32次统计从最终PDF Table3转录：8正确、6错误、17未表达、1混合/其他；完整成功5/32；完成操作10/32，其中5/10错目标；方向符合18/32；所有四次均正确0/8。它们不是本包训练素材的性能统计。

动作差异图的0.0076/0.0674 rad对应论文舍入值。前者是memory swap，后者是seed变化。它们不是纯硬件噪声分解。AA模块只说明所示重复存在差异，不能推广为精确硬件方差估计。

不使用未最终核验的真机连续物理价值U，不从人工目标标签反推出米制坐标。原始分析快照含有历史候选几何结果，仅读作来源档案，不作为最终主图结论。

## 视觉与匿名处理

按用户最终要求，黑底、白字为主，辅助用灰阶；阶段条只用文字和细线，不使用彩色卡片或圆角装饰。1920×1080、30 fps、无音轨；源相机为640×480，排版采用等比放大，不声称新增真实细节。英文文字与语义目标圈是解释层，不是自动目标检测或几何标定。镜头没有翻转左右，没有透视扭曲、生成补帧或重新着色物体。

两处后方台面设备标签使用固定区域模糊。该区域可能短暂覆盖经过的背景结构或机械臂局部，不用于修改目标物体或制造轨迹。选中画面无人脸；移除音轨可避免原始对话进入投稿片。包内研究来源记录含本机绝对路径和原始标识，供内部复核；对外投稿只取选定视频/图片，并自行附上Task2来源说明。

现成Fig.6素材包中的task1补拍说明记载为同来源、不同前缀臂，因此没有将该素材包当成主左右语义配对的来源。本包正式history/query/suffix关联来自ledger。

## 可复查性

每个native视频配一份逐输出帧source map，保留消息ID、源header时间、bag接收时间和显示时间。30fps仅用于显示；最近录制帧超过65ms时显示黑底SOURCE GAP，完整导出不会把源缺失用上一帧覆盖。原始相机低于30fps时允许最近邻重复帧，这与生成插帧不同。

所有来源目录仅只读；未启动backend、未新增rollout、未修改训练集或正式标签，未对原始episode树或海量帧计算内容SHA-256。
